# $LIDE Game Assets

This directory contains all visual assets for the $LIDE game, organized by category.

## Directory Structure

| Directory | Count | Description |
|-----------|-------|-------------|
| `weapons/` | 48 | Weapon imagery including pistols, rifles, SMGs, shotguns, knives, and attachments |
| `drugs/` | 36 | Drug imagery including weed, crack, lean, ecstasy, meth, heroin, pills, and more |
| `sprites/` | 81 | Game sprite sheets and character sprites for the mini-games |
| `game-pics/` | 35 | Reference images, mockups, and concept art for the game |
| `generated/` | 21 | AI-generated assets including logos, backgrounds, character art, and icons |

## Key Generated Assets

The `generated/` directory contains custom AI-generated art used on the $LIDE website, including the $LIDE logo with textured letters (diamonds, gun, weed, money, pills), character portraits for the Shooter, Dealer, and Enforcer classes, city skyline and street scene backgrounds, and game mechanic icons.

## Roadman GFX

The `roadman-gfx-logo.png` file in the root of this directory is the Roadman GFX logo, credited as the art direction for the $LIDE game.

## Usage

These assets are referenced by CDN URL in the $LIDE website. The original files are stored here for version control and backup purposes.
